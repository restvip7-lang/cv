# Ануар Усманов — персональный сайт

Статический сайт на HTML, CSS и JavaScript. Русская, английская и турецкая версии. Node.js и установка пакетов не требуются.

## Структура

- `dist/` — готовый сайт, эту папку нужно указать как корень публикации (Output Directory).
- `build.py` — исходные тексты и генератор HTML, sitemap и robots.txt.
- `dist/style.css` — оформление и адаптивная вёрстка.
- `dist/app.js` — вкладки, история переходов и диалоги.
- `dist/assets/` — портрет, favicon и два резюме PDF.

## Локальный просмотр

Из папки проекта выполните:

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте http://127.0.0.1:4173/ . Не открывайте index.html двойным щелчком: ссылки на ресурсы начинаются от корня сайта.

## Редактирование

Тексты всех языков находятся в build.py. После изменения запустите:

```sh
python build.py
```

CSS и JavaScript редактируются непосредственно в dist. Обновлённые файлы dist также нужно сохранять в Git.

## Размещение

Архив предназначен для добавления в Git-репозиторий. Публикация при сборке архива не выполнялась. Готовые файлы находятся в dist; отдельная сборка на хостинге не обязательна.

Сайт рассчитан на корень домена. Обычный GitHub Pages по адресу username.github.io/repository/ потребует адаптации абсолютных путей. Для размещения на собственном домене используйте dist как корень сайта.

## SEO

Canonical, hreflang, sitemap и структурированные данные настроены на https://www.usmanov.biz/. При смене основного домена измените BASE в build.py и перегенерируйте HTML. Перед публичным запуском проверьте HTTPS, редиректы старых страниц, ответы 404 и доступность языковых URL. Поисковые кабинеты и отправка sitemap не настроены этим архивом.

Все тексты присутствуют в HTML. Без JavaScript показываются все разделы. При обычных размерах экрана вкладки позволяют избежать прокрутки; при экстремальных размерах и увеличении текста сохраняется доступ ко всему содержимому.

## Медиа и данные

Портрет создан с помощью ImageGen по одобренному владельцем референсу и оптимизирован в WebP. Иконка WhatsApp — Simple Icons (https://simpleicons.org/). PDF-резюме и контакты владельца включены намеренно; учитывайте их доступность при создании публичного репозитория.

В архиве нет .git, приватных настроек Sites, токенов, временных скриншотов и локальных QA-скриптов.
